# Anjali Modi — Full Stack Developer Portfolio

A modern, high-performance portfolio website featuring a **60fps scroll-driven canvas animation engine** (176 frames), glassmorphism, responsive grids, and full stack engineering showcases.

---

## 🚀 Features

- **Dynamic Background Canvas Engine**: 176 high-resolution frames synchronized with scroll progress via physics-based interpolation (Lerp `0.085`).
- **High-DPI Retina Support**: Automatically scales to `devicePixelRatio` with aspect-ratio cover centering across all viewports.
- **Progressive Preloader**: Instant Frame 1 rendering (<50ms) with background asset caching and live progress ring.
- **Modern Glassmorphic Aesthetic**: Deep dark tones (`#0d0707`), subtle crimson glows (`#e63946`), refined typography (`Bebas Neue`, `Syne`, `Outfit`, `Space Grotesk`).
- **Full Stack Engineering Showcases**:
  - Services: Full Stack Development, Backend & APIs, Frontend Systems, Cloud & DevOps, Database Design.
  - 5-Phase Engineering Process: Discover & Plan, System Architecture, Core Development, Test & Optimize, Deploy & Monitor.
  - Tech Stack: React/Next.js, TypeScript, Node.js, PostgreSQL, Docker/AWS.
  - Project Cards: Elevate Platform, Nexus Finance Engine, Travelora Cloud, Veloce Telemetry App.
- **Interactive Connect Area**: Direct GitHub and LinkedIn QR codes, email, phone, and location links.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, CSS Grid & Flexbox), JavaScript (Canvas 2D, Lerp Engine, rAF Loop).
- **Assets**: 176 PNG video frames (`frames/`), SVG vector icons, custom photography.
- **Server**: Lightweight zero-dependency Node.js static server (`server.js`).

---

## 🏃 Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AnjaliModi2/anjali-modi.git
   cd anjali-modi
   ```

2. **Start the local server**:
   ```bash
   node server.js
   ```
   Or open with any static server:
   ```bash
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000`
